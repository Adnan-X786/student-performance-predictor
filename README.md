# 🎓 Student Performance Predictor

A Machine Learning project that predicts student academic performance based on:

- Study Hours
- Attendance
- Assignment Completion

## Tech Stack

- Python
- Scikit-Learn
- Pandas
- NumPy
- Streamlit

## Installation

```bash
pip install -r requirements.txt
```

Train model:

```bash
python train_model.py
```

Run app:

```bash
streamlit run app.py
```

## Features

✅ Machine Learning Model

✅ Real-time Predictions

✅ Interactive Web Interface
